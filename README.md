# Starship

A short game wrote in Java for learning.
You are a spaceship and you need to dodge some asteroids during your run, try to get the higher score you can.

## Environnement

- [Java](https://www.java.com/fr/)
- [Swing](https://docs.oracle.com/javase/8/docs/api/javax/swing/package-summary.html) for the window, the keyboards inputs and the game actions

## Features

- Move the ship with arrows
- Calculation of the time elapsed between each window update (representated by "dt" in the project)
- Stars and moving background
- Optimization for smoother experience
- Asteroids which spawn each 200ms
- Life system (2 chances)
- Program close when you lose (when hp < 2)
